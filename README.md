# Project Exedra-ism

## What is this project about?
Have you ever wanted to make an Exedra character sheet for yourself or for fun and just found out that the process is a huge hassle?

"Canon compliant" OC sheets has to follow several naming convention and wording convention. A lot of which require you to go out of your way and scout the Wikis for a long time in order to find the right words. Imagine doing this for every single kit you ever want to make.

That is what this project is for. The purpose of Project Exedra-ism is the ease of creativity. Allowing you to focus only on making and designing kits, and handling the wording automatically for you.
